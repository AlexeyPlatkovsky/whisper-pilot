User-approved Recorder storage decision (2026-09-12): Recorder is a true recorder and retains raw microphone audio locally until the user deletes the session. Capture is written as normalized 16 kHz mono signed-16 PCM in an app-owned crash-tolerant CAF .partial artifact; successful Stop exposes playback and atomically promotes it to .caf. WAV is a user-triggered export copy. Transcript editing/copy/export never rewrites the retained audio, and exported files are never owned or deleted by WhisperPilot. Interrupted durable .partial recordings remain visible for Recover or Delete; disk/device/ASR failures preserve every durable checkpoint and show an actionable state.

Resolved implementation boundaries after independent requirements review: preflight permission/model/default-device/caption availability before creating durable session state, and failed preflight is not retained in history. Finalizing is an authoritative Rust coordinator phase retaining live-source ownership through tail ASR, audio flush/fsync/close, atomic .partial-to-.caf rename, and DB completion. Audio checkpoints target at most one second of unflushed PCM. Recovery reconciles both finalizing-row + final .caf and completed-row + .partial without discarding either artifact. Recorder v1 uses the system default input chosen at Start; a mid-session default change does not migrate the stream, while active-device loss stops into a recoverable error. Delete failure keeps the session visible as Delete failed / Retry. Shortcut replacement failure keeps the prior registered/persisted chord; initial registration failure leaves it disabled. During Starting/Capturing/Finalizing of any live source, conflicting starts are rejected; Recorder shortcut during its own capture requests Stop, and during Finalizing is ignored. If the non-activating caption surface disappears after hidden capture begins, capture stops and finalizes with an actionable UI error.
