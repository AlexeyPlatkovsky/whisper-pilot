# AI Reference Documents

This directory holds concise, project-local context for AI-assisted work. It is
supporting context, not product or engineering authority.

## Contents

| Document | Purpose | Update when |
| --- | --- | --- |
| `project_specification.md` | Project purpose, user role, authority order, and AI-work expectations | The product scope, active AI tooling, or working practices materially change |

## Authority And Scope

`AGENTS.md` is the project-wide operating contract. Product and engineering
authority remains in `docs/`, as mapped by `docs/INDEX.md`, and current runtime
behavior remains in the source code and tests. Do not use this directory to
override those sources or to record secrets.

The `.manifesto/` directory is a template library only. It is not a
project-local operating authority and is outside the normal maintenance scope
of these reference documents.
